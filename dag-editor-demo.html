Keyboard shortcuts

Click canvas → add node
Drag output port → edge forward
Drag input port → edge backward
Drop on canvas → new node

Dbl-click node → rename
Del / Backspace → delete
Enter → rename selected
N → new node at centre
Tab → cycle selection
Esc → deselect
L → one-shot auto-layout
Shift+L → pin auto-layout
Dbl-click Layout btn → pin
Ctrl+Z → undo
Ctrl+Shift+Z → redo
Scroll → zoom
Alt+drag → pan
